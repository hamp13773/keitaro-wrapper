# Keitaro Wrapper

Веб-инструмент для создания кампаний и редактирования офферов в Keitaro. Сервер на FastAPI, черновики в SQLite через SQLAlchemy, миграции в Alembic. Интерфейс работает в браузере без сборки фронтенда.

## Запуск за несколько минут

Понадобится Python 3.11 или новее. Выполните команды из корня репозитория.

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env
alembic upgrade head
uvicorn app.main:create_app --factory --host 127.0.0.1 --port 8000
```

Откройте [интерфейс](http://127.0.0.1:8000) или [OpenAPI](http://127.0.0.1:8000/docs). В Windows команда активации для PowerShell — `.venv\Scripts\Activate.ps1`. Миграция создаст `keitaro-wrapper.db` в текущем каталоге.

Демо-режим сразу показывает кампанию с тремя офферами и синтетической статистикой. Создайте кампанию или добавьте оффер в существующий поток. Кампании демо хранятся в памяти процесса и сбрасываются при его перезапуске. В реальном режиме конфигурация кампаний хранится в Keitaro, а черновики переживают перезапуск приложения.

## Подключение к тестовому Keitaro

1. В профиле Keitaro откройте вкладку **API ключи** и возьмите выданный ключ Admin API.
2. В локальном файле `.env` задайте параметры ниже. Для `KEITARO_URL` используйте HTTPS-адрес выданного сервера без пути `/admin`.
3. Перезапустите приложение. В настройках по умолчанию оно слушает `127.0.0.1`.

```dotenv
KEITARO_MODE=live
KEITARO_URL=https://keitaro.example.org
KEITARO_API_KEY=ваш_ключ_Admin_API
CAMPAIGN_PREFIX=test_karpov_
REPORT_TIMEZONE=Europe/Moscow
```

Для создания и редактирования аккаунту нужны каталоги доменов, групп кампаний, источников и офферов, а также права на запись кампаний и потоков. Для получения кликов и конверсий нужны права на отчёты. Значения из `.env` читает сервер приложения. Для общего доступа понадобится отдельный слой аутентификации.

## Как пользоваться

**Создание.** Введите название, двухбуквенный код страны ISO 3166-1, выберите оффер, домен, группу и источник. К имени добавится `test_karpov_`. В режиме ротации по позиции первый поток отправит трафик из выбранной страны на Google через HTTP-редирект. Поток по умолчанию отправит остальной трафик на выбранный оффер с долей 100%. Приложение включает кампанию после сверки настроек в Keitaro.

**Редактирование.** Откройте кампанию с настроенным префиксом и выберите поток со схемой «Лендинги и офферы». Добавляйте, удаляйте и возвращайте офферы в черновике. Нажмите **Применить в Keitaro**, чтобы отправить весь набор офферов потока, или **Отменить черновик**, чтобы вернуться к текущей конфигурации. Удаление касается связи с потоком. После удаления последнего оффера поток остаётся без назначения оффера, пока вы его не добавите или не вернёте.

**Доли.** Можно закрепить целое значение процента. При пересчёте остаток распределяется поровну между активными офферами без фиксации, целочисленный остаток получают первые строки. Например, при одной закреплённой доле 25% и двух свободных получатся 25%, 38%, 37%. Удалённый оффер показывает 0%. При наличии активных офферов изменения распределяют в сумме ровно 100%. Источник кликов и конверсий в режиме `live` — отчёт Keitaro за последние семь календарных дней, включая текущий.

**Предпросмотр.** Перед применением приложение показывает добавленные и удалённые офферы, прежние и будущие доли и изменения фиксации. Например, при добавлении четвёртого оффера `34% / 33% / 33%` превращаются в четыре доли по `25%`.

**Обновление.** Кнопка **Обновить из Keitaro** перечитывает кампанию, справочники и выбранный поток. При изменении офферов или долей в Keitaro приложение показывает, какие значения изменились с момента начала правок, и блокирует применение черновика. Чтобы продолжить с текущим распределением, отмените черновик и повторите правки. При успешной отправке приложение проверяет сохранённое распределение повторным запросом.

**История и возврат.** Разверните **История применений** под офферами потока. История начинается с первого применения после обновления приложения. Каждая запись показывает время применения и изменения, подтверждённые Keitaro. Кнопка **Вернуть предыдущее распределение** создаёт черновик из состояния перед последней записью. Проверьте предпросмотр и примените его обычным способом. Когда в потоке есть черновик или офферы после последнего применения изменились в Keitaro, возврат блокируется.

## Миграции и проверки

После обновления исходников остановите приложение, примените миграции и запустите его снова.

```sh
alembic upgrade head
alembic current
```

`DATABASE_URL` задаёт SQLAlchemy URL базы черновиков. По умолчанию это `sqlite:///./keitaro-wrapper.db`. Alembic и приложение используют одну настройку.

```sh
python -m pip install -r requirements-dev.txt
python -m pytest -q
ruff check .
```

В тестах HTTP-запросы адаптера обрабатывает `httpx.MockTransport`. Проверяются создание и откат при отказе второго потока, доли и статистика, черновики после перезапуска, защита кампаний с другим префиксом, конфликт версий и сохранность настроек потока.

[Справочник Keitaro Admin API](https://admin-api.docs.keitaro.io/) · [Документация по потокам](https://docs.keitaro.io/en/campaigns-and-streams/streams.html)
